# 分麵包 · 公平分割遊戲 🥖

一個以 HTML5 Canvas 打造的「**最後裁切者（Last Diminisher）**」公平分割遊戲。
2–10 位玩家輪流在麵包上自由劃刀、挑塊、傳遞，最後依「各人分到的面積誰最接近公平值」計分。
無印良品（MUJI）風格：溫潤大地色、留白、細線。手機／電腦皆可玩（RWD）。

## 玩法

1. 選擇玩家人數（2–10）。
2. 起始玩家選一種麵包（10 款）或隨機。
3. 用手指／滑鼠**自由劃一刀**（可畫不規則線）把麵包切成兩塊。
4. 切割者挑一塊自己覺得公平的留下（另一塊放回餐盤），把留下的當「爭議塊」往下傳。
5. 下一位玩家選 **合格（Pass）** 或 **裁切（Cut）**：
   - 合格 → 換下一位判斷。
   - 裁切 → 在爭議塊上再切一刀、挑一塊續傳，餘塊放回餐盤。
6. 一輪走完，**最後一位裁切者**贏得爭議塊；若無人裁切，歸起始者。
7. 換下一位當起始者重複，直到「最後一位以外」的玩家都當過起始者。
8. 最後一位玩家收下餐盤上**所有剩餘塊**。
9. 計分：目標 = 總面積 ÷ 人數；各玩家面積越接近目標名次越前，20 / 18 / 16… 遞減給分。
10. 可繼續下一大回合或重新開始。

## 技術

- **HTML5 Canvas + 原生 ES Modules**，零框架、零建置、零相依。
- **向量麵包**：10 款以「形心 + 半徑函數」程序生成的多邊形，而非 AI 點陣圖——因為切割、面積計算、放回餐盤都需要幾何多邊形。
- **幾何引擎**（`js/geometry.js`）：Shoelace 面積、射線法點內判定、線段相交、**自由劃線切多邊形**。
- **狀態機**（`js/game.js`）：實作 Last Diminisher 流程與計分。
- **RWD**：Retina 畫布、觸控／滑鼠雙輸入、行動裝置優先版面。

## 檔案結構

```
bread-cut-game/
├── index.html
├── css/style.css        # MUJI 風格
└── js/
    ├── geometry.js      # 多邊形幾何：面積 / 切割 / 內判定
    ├── breads.js        # 10 款程序生成向量麵包
    ├── game.js          # Last Diminisher 狀態機 + 計分
    ├── render.js        # Canvas 繪製
    └── main.js          # 輸入處理 + UI 串接
```

## 本機執行

因為使用 ES Modules，需以 HTTP 伺服器開啟（不要用 `file://`）：

```bash
cd bread-cut-game
python3 -m http.server 8000
# 開 http://localhost:8000
```
